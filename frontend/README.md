# Авто-Интеллект — фронтенд

React + TypeScript + Vite, React Router, Tailwind CSS.

## Запуск

Нужен Node.js 22.12+. Сначала запустите бэкенд

```bash
cd frontend
npm ci
npm run dev
```

Откройте http://127.0.0.1:5173. В PowerShell с запретом `.ps1` используйте `npm.cmd` вместо `npm`.

Запросы `/api` по умолчанию направляются на `http://127.0.0.1:8000`. Другой адрес задаётся через `API_PROXY_TARGET` в `.env` (пример — `.env.example`). Для размещения фронтенда отдельно от API задайте `VITE_API_URL` перед сборкой.

## Страницы

| Страница | Путь | Состояние |
| --- | --- | --- |
| Login | `/` | Регистрация и вход по email и паролю |
| Home | `/home` | Описание проблемы, теги и кнопка расчёта |
| CarProfile | `/car` | Справочники API, создание авто и запрос ремонта |
| RepairEstimate | `/repair` | Диапазон цены, уверенность и раскрывающиеся блоки по макету |
| CarValuation | `/valuation` | Цена «как есть», оценка после ремонта и прирост стоимости |
| Scenarios | `/scenarios` | Три сценария, рекомендация и раскрывающееся обоснование |
| History | `/history` | Сохранённые расчёты из API, поиск и просмотр |

Кнопка «Назад» в шапке возвращает на предыдущую страницу внутри приложения. При прямом открытии URL предусмотрен переход к предыдущему шагу (`/repair` → `/car`, `/car` → `/home`, `/home` → `/`). На стартовом экране без предыдущего перехода кнопка отключена. Все разделы доступны в раскрывающемся меню пользователя в шапке. Для неизвестного адреса есть страница 404.

Вход требуется для работы с расчётами. Токен хранится в текущей вкладке; при истечении сессии откроется форма входа. Яндекс и Apple пока не подключены.

Описание должно содержать от 2 до 1000 символов. Тег заполняет описание; повторное нажатие выбранного тега очищает его. Кнопка расчёта ведёт на `/car`.

Марки, модели и регионы загружаются с сервера. Проверяются обязательные поля, год выпуска и целый пробег от 0 до 5 000 000 км. Пробег можно вводить с пробелами: `85 000`.

На `/repair` показывается диапазон стоимости из API. На `/valuation` вводится целая цена от 1 до 100 000 000 ₽ и загружается оценка после ремонта. `/scenarios` показывает серверную рекомендацию и сохраняет расчёт.

Основной путь: описание → автомобиль → ремонт → оценка авто → сценарии → сохранить → история. После перезагрузки страницы ремонта или оценки нужно снова пройти форму автомобиля.

Расчёты в `/history` загружаются из API и остаются после перезагрузки. Поиск работает по загруженным авто и датам; следующие записи добавляются кнопкой «Загрузить ещё». «Открыть» показывает сохранённые данные выбранной записи.
