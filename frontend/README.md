# Авто-Интеллект — фронтенд

React + TypeScript + Vite, React Router, Tailwind CSS. Для запуска бэкенд не нужен.

## Запуск

Нужен Node.js 22.12+ (рекомендуется 24 LTS).

```bash
cd frontend
npm ci
npm run dev
```

Откройте http://127.0.0.1:5173. В PowerShell с запретом `.ps1` используйте `npm.cmd` вместо `npm`.

## Страницы

| Страница | Путь | Состояние |
| --- | --- | --- |
| Login | `/` | Форма телефона или email, валидация, кнопки Яндекс / Apple |
| Home | `/home` | Описание проблемы, теги и кнопка расчёта |
| CarProfile | `/car` | Форма автомобиля по PNG и CSS, локальный справочник и сохранение |
| RepairEstimate | `/repair` | Диапазон цены, уверенность и раскрывающиеся блоки по макету |
| CarValuation | `/valuation` | Цена «как есть», оценка после ремонта и прирост стоимости |
| Scenarios | `/scenarios` | Три сценария, рекомендация и раскрывающееся обоснование |
| History | `/history` | Заглушка с заголовком |

Кнопка «Назад» в шапке возвращает на предыдущую страницу внутри приложения. При прямом открытии URL предусмотрен переход к предыдущему шагу (`/repair` → `/car`, `/car` → `/home`, `/home` → `/`). На стартовом экране без предыдущего перехода кнопка отключена. Все разделы доступны в раскрывающемся меню пользователя в шапке. Для неизвестного адреса есть страница 404.

После корректного телефона или email форма открывает `/home`. Для телефона допустимы 10–15 цифр, начальный `+`, пробелы, скобки и дефисы. Это демонстрация интерфейса: запросы на авторизацию не отправляются, аккаунт и токен не создаются. Яндекс / Apple показывают сообщение о том, что такой вход пока недоступен. Их интеграция не входит в неделю 1.

Кнопка «Рассчитать стоимость» отключена для пустой строки и пробелов. Поле ограничено 1000 символами. Пять тегов соответствуют PNG: тег заполняет описание, повторное нажатие выбранного тега очищает его. С непустым описанием кнопка ведёт на `/car`. Ссылка «Добавить автомобиль» также ведёт на `/car`. Описание сохраняется при переходах внутри приложения; после перезагрузки очищается.

## Профиль автомобиля — экран 3
Марка определяет список моделей; при изменении марки модель сбрасывается. Проверяются все обязательные поля, год 1900–текущий и целый неотрицательный пробег. Пробег можно вводить с пробелами: `85 000`. Для региона есть список и ручной ввод.

На `/repair` показан пример из макета (18 000–24 000 ₽), а не реальный расчёт. Данные автомобиля берутся из формы; сохранение расчётов пока не подключено.

На `/valuation` цена «как есть» вводится цифрами. Оценка после ремонта — пример 680 000 ₽; разница обновляется при вводе. Кнопка ведёт на `/scenarios`, где сравниваются три варианта на примере из макета. «Почему так?» раскрывает арифметику; сохранение расчётов пока не подключено.
